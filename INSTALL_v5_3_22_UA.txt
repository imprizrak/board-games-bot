Styloteka 5.3.22 — повторення завершеної події
===============================================

ЩО ДОДАНО
- Для адміністратора у вкладці «Події» → «Історія» з'являється кнопка «🔁 Повторити подію».
- Форма повторення копіює назву, опис, приватну адресу, настільні ігри, вартість,
  посилання на банку monobank, кількість місць і обкладинку.
- Стару дату навмисно не копіює: для нової події треба вибрати сьогоднішню або майбутню дату.
- Час копіюється, але його можна змінити; будь-які інші поля теж можна редагувати.
- Скидає Quests Inc URL, кількість записів і відмітки присутності. Для іншого заходу
  слід вказати НОВЕ посилання Quests, якщо воно потрібне.
- Створюється НОВА подія зі своїм ID і статусом scheduled. Історична подія лишається без змін.
- Старі RSVP/учасники, квитанції, оплати, QR-реєстрації, нагадування, повідомлення групи
  і вибрані учасниками ігри не копіюються.
- Після створення переходить у «Майбутні». Новий анонс надсилається звичайним механізмом.

ВСТАНОВЛЕННЯ
1. У репозиторії GitHub https://github.com/imprizrak/board-games-bot замінити
   app.py та index.html на однойменні файли з цього архіву.
2. Дочекатися успішного автоматичного деплою у Render (гілка main).
3. Оновити Telegram Mini App (закрити й відкрити знову).
4. Відкрити «Події» → «Історія» → завершену подію → «🔁 Повторити подію».
5. Обрати нову дату, перевірити/змінити час, адресу, ігри й оплату та натиснути
   «Створити повторну подію».

БАЗА ДАНИХ
- Нова SQL-міграція для цієї функції НЕ потрібна.
- Додані SQL-файли з попередніх версій збережені лише для довідки/нової інсталяції;
  НЕ запускайте їх повторно без необхідності.
