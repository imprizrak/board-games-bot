Styloteka v5.3.29 — очищення бібліотеки за скриншотом

Прибрано з екрана бібліотеки:
• підвкладки «Вішліст», «Історія», «Статистика»;
• увесь блок «Ігровий компас» (гра дня, випадкова гра, сортування, скидання фільтрів, недавно відкриті);
• велику кнопку «Модерація нових ігор» (механізм обробки заявок у коді збережено, але з бібліотеки більше не відкривається).

Залишено:
• бібліотеку, рядок пошуку, фільтри за жанрами;
• zip-lock оформлення карток ігор;
• кнопку «+» для додавання гри;
• три нижні вкладки «Події», «Бібліотека», «Інструменти»;
• увесь серверний код, події, оплати і дані у Supabase без змін.

Перевірено: адаптація бібліотеки на 320, 375, 393, 430, 768 px;
існуючі тести навігації, компактної нижньої панелі і вибору гравця.

Встановлення:
1. Відкрити GitHub репозиторій, підключений до Render.
2. Замінити index.html на файл з цього архіву.
3. Дочекатися автоматичного розгортання і повторно відкрити Telegram Mini App.

Не потрібно змінювати app.py або запускати SQL-міграції.
Доки index.html не встановлено, поточний робочий сайт не зміниться.
