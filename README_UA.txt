Styloteka 5.3.35 — виправлення «Вибір гравця» для Telegram / iPhone

Встановлення:
1. Відкрийте index.html з цього ZIP.
2. Замініть ним index.html у головній гілці GitHub проєкту Styloteka.
3. Дочекайтеся успішного розгортання Render, закрийте Telegram Mini App і відкрийте його заново.
4. Перейдіть у «Інструменти» → «Вибір гравця».

Що виправлено:
• Повноекранна панель більше не обмежується стилями вкладки «Інструменти».
• Нижня навігація тимчасово ховається, а область дотиків займає всю доступну висоту WebView.
• Не викликається нативний Telegram requestFullscreen, який накладав кнопку «Закрити» на текст/ігрове поле.
• Інструкція й вихід винесені в окрему верхню зону; кнопка «Скинути» — внизу.
• Дотики під час анімації відстежуються для правильного автоматичного скидання після визначення переможця.
• Немає прив'язки до Telegram-профілів чи нагород за вибір.

Не змінювалися: app.py, база Supabase, оплати, каталог ігор, картки бібліотеки, події, інші інструменти.

Тестування: тест test_picker_fullscreen.py з перевіркою мобільної геометрії, двох одночасних дотиків, вибору переможця, автоматичного скидання та виходу пройшов для 320, 375, 393, 430, 768 px у Chromium. Також пройдено регресійні тести навігації, календаря, карток бібліотеки та кубиків.

Важливо: реальну роботу в Telegram на iOS потрібно перевірити після публікації; браузерні тести не є тестом на фізичному iPhone.
