Styloteka 5.3.30 — Кубики без прив’язки до профілів

Прибрано з вкладки «Інструменти» → «Кубики»:
• блок «Хто кидає кубик» та список профілів;
• примітку про прив’язку до Telegram ID;
• автоматичне надсилання результатів кидків у профіль та нарахування досягнень за кидки;
• зайве фонове завантаження профілів для кубиків.

Збережено:
• кубики d4, d6, d8, d10, d12, d20, d100;
• анімацію, вібровідгук і локальну історію останніх 8 кидків;
• «Вибір гравця» без імен і профілів, «Лічильники»;
• «Події», «Бібліотеку» в стилі zip‑пакетиків і компактну нижню панель.

Ніякі дані чи досягнення в Supabase не видаляються.

Встановлення:
1. Відкрити GitHub репозиторій, з якого Render виконує deploy.
2. Замінити index.html файлом із цього архіву.
3. Дочекатися завершення deploy і повторно відкрити Telegram Mini App.

НЕ потрібні зміни app.py або SQL-міграції.
До встановлення на Render робочий бот не зміниться.

Перевірено: п’ять ширин для кубиків, усі сім розмірів для навігації,
збереження бібліотеки та функцій вибору гравця.
