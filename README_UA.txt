STYLOTEKA 5.3.33 — НЕОНОВИЙ СКЛЯНИЙ UI
====================================

Це пакет оновлення інтерфейсу Telegram-мінібота, підготовлений
на основі Styloteka 5.3.31 / наявного index.html з тією ж логікою.

ВСТАНОВЛЕННЯ
1. Зробіть резервну копію нинішнього index.html у GitHub.
2. Замініть index.html у корені репозиторію файлом з цього архіву.
3. Збережіть зміни/зробіть commit у гілку, яку деплоїть Render.
4. Після успішного деплою перезапустіть Telegram-мінібот.
   Якщо старий стиль кешується, закрийте WebApp повністю та відкрийте знову.

ЩО ЗМІНЕНО
• Нові блакитно-фіолетові неонові glassmorphism стилі.
• Скляні картки подій із обкладинкою або іконкою-заглушкою.
• Фільтри та пошук подій; вкладки Майбутні / Історія залишилися.
• Бібліотека ігор у прозорих пакетиках з новою палітрою.
• Нова стилістика вкладки Інструменти, кнопок, модальних вікон і форм.
• Збережена компактна нижня панель з трьома вкладками.
• Порожній екран подій: «На цей час пакет пустий».

ВАЖЛИВІ ПРИМІТКИ
• Без змін app.py, платіжних API, бази Supabase або Telegram-команд.
• Категорії «Настолки / Чаювання / Творчість» визначаються тимчасово
  за назвою, описом і назвою гри. Для надійної категоризації в майбутньому
  потрібне окреме поле типу події на сервері та у формі створення.
• Скриншоти прев'ю з ТЕСТОВИМИ ДАНИМИ, це не реальні анонси.
• Тести Chromium не замінюють остаточної перевірки у Telegram WebView
  на реальному iPhone / Android.
• Код НЕ опубліковано на Render. Встановлення виконується вручну.
