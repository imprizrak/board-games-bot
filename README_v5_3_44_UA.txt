STYLOTEKA v5.3.44 — ПОДІЇ ЯК ПУБЛІКАЦІЇ В INSTAGRAM

ЩО ЗМІНЕНО
1. У вкладці «Події» прибрано верхню горизонтальну стрічку фільтрів «Усі / Настолки / Чаювання / Творчість».
2. Кожна подія оформлена як публікація: невелика шапка Styloteka з датою, велика обкладинка на всю ширину, нижче — назва, вартість, опис, кількість місць і кнопки.
3. Обкладинки показуються у вихідному співвідношенні сторін (портретні і квадратні не обрізаються).
4. Пошук, майбутні/історія, заявка учасника, редагування, оплата, квитанції, QR-відмітка, прихована адреса та список учасників не видалені.
5. Відключено стілси за фактичне відвідування: немає поля винагороди в формі, сервер при створенні та редагуванні встановлює нуль.
6. Нарахування за QR-сканування вимкнене безпосередньо в Supabase. QR-сканування й облік присутності збережені.
7. Раніше нараховані стілси, баланси та завершені події не змінювалися. Інші способи заробляння стілсів (поза відвідуванням) не змінювалися.

ВЖЕ ЗАСТОСОВАНО В SUPABASE
- Значення за замовчуванням attendance_reward_stils = 0 для events та event_submissions.
- Значення винагороди 0 для майбутніх подій та невирішених заявок.
- Функція styloteka_confirm_event_checkin більше не створює нарахування стілсів, але підтверджує відвідування.
- Файл disable_event_attendance_stils.sql додається як документація змін. НЕ ПОТРІБНО запускати його повторно.
