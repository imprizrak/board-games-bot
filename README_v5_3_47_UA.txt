Styloteka v5.3.47 — легкий блюр нижньої навігації

База: Styloteka 5.3.46 (компактна прозора панель та автозаповнення настільних ігор).

Зміни тільки в index.html:
- Плаваюча нижня панель має легке розмиття фону: backdrop-filter: blur(8px) saturate(118%).
- Напівпрозора темно-синя підкладка (приблизно 10% непрозорості) для читабельності поверх карток.
- Активна вкладка має делікатну напівпрозору підкладку.
- Розміри та форма НЕ змінювались: 302 × 56 px (290 px на вузькому екрані), округлення pill.
- Кнопки 46 px заввишки, підсвічені контури, safe-area та відступ від нижнього краю збережені.
- Для системного налаштування зменшеної прозорості передбачений контрастніший фон без блюру.

Встановлення:
1. Якщо в GitHub уже встановлена 5.3.46, замінити тільки index.html у корені репозиторію.
2. Якщо 5.3.46 немає, встановити index.html, app.py та game_autofill.py з цього архіву.
3. Зробити commit у GitHub; якщо увімкнено autoDeploy, Render розгорне зміну.
4. Відкрити мінібот у Telegram, перевірити всі вкладки та нижню панель на iPhone/Android.

Ніяких змін у Supabase немає. Цей ZIP сам по собі НЕ встановлює оновлення на Render.

Тести:
python test_soft_blur_nav.py
python test_ios_widgets_regression.py
python test_game_autofill_existing.py

Перевірено в Chromium на розмірах 320, 375, 393, 430, 768 px:
- CSS blur, напівпрозорість, розміри, зона натискання та відсутність горизонтального скролу;
- переключення «Події / Бібліотека / Інструменти»;
- регресія: віджети, кубики, лічильники, вибір гравця та автозаповнення нової/наявної гри.
Реальні Telegram WebView iOS/Android потребують перевірки після розгортання.
