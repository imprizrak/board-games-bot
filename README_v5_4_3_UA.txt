Global Librarian: пошук у шести мовних версіях Wikipedia паралельно з українськими каталогами. MyMemory перекладає короткі уривки українською без ключа, але має квоти. Фоновий агент автоматично заповнює лише порожній опис із Wikipedia, з посиланням на джерело та умовним PATCH, що захищає ручні зміни. Фото залишаються пропозиціями. Якщо переклад недоступний, опис не додається. Замініть app.py; для фонового режиму STYLOTEKA_CORE_ENABLED=1. Зовнішні запити та Render не протестовано.
