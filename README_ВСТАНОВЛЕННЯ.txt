STYLOTEKA v4.5 — PWA ТА ОФЛАЙН-БІБЛІОТЕКА

Що змінилося
• /offline — окрема офлайн-бібліотека, яку можна додати на головний екран телефона.
• Встановлювана PWA з іконкою, назвою та offline shell через Service Worker.
• Пошук настолок, випадковий вибір, збережені описи й майбутні/минулі події.
• Кнопка «Оновити дані» зберігає останню публічну копію у браузері.
• Кнопка «Зберегти обкладинки» завантажує до 35 зображень за бажанням.
• Головна версія Telegram Mini App теж кешує публічні ігри й події та показує попередження про відсутність мережі.
• Особисті дані учасників, платежі, магазин, адміністративні дані та API авторизації НЕ кешуються.

ВСТАНОВЛЕННЯ
1. Збережіть резервну копію поточних index.html та app.py.
2. Скопіюйте до кореня репозиторію GitHub ВСІ файли з архіву:
   index.html
   app.py
   offline.html
   offline.js
   offline-bridge.js
   sw.js
   manifest.webmanifest
   icons/icon-192.png
   icons/icon-512.png
   icons/icon-512-maskable.png
   (README_ВСТАНОВЛЕННЯ.txt — не обов'язковий)
3. Важливо: збережіть папку icons і точні імена/шляхи файлів.
4. Дочекайтеся, поки Render завершить деплой; перевірте /health і /offline.
5. З iPhone відкрийте https://board-games-bot-hkfp.onrender.com/offline в Safari,
   дочекайтеся завантаження ігор, натисніть «Оновити дані», далі
   «Поділитися» → «На початковий екран». Android: Chrome → «Встановити застосунок».
6. Перевірте офлайн: запустіть PWA із домашнього екрана, увімкніть авіарежим,
   повністю закрийте PWA і відкрийте знову.

ВАЖЛИВІ ОБМЕЖЕННЯ
• Сам Telegram НЕ гарантує запуск Mini App без інтернету. Для надійного запуску
  використовуйте встановлену PWA-версію з іконки телефона.
• Для нового пристрою/браузера потрібно хоча б один раз відкрити /offline онлайн
  і завантажити каталог. Кеш Telegram та Safari/Chrome може бути розділений.
• Без інтернету можна тільки ПЕРЕГЛЯДАТИ раніше збережені публічні дані.
• Нові записи на подію, RSVP, голосування, оплата monobank, магазин, XP,
  адмін-операції та зовнішні PDF-правила працюють виключно онлайн.
• Розклад офлайн може застаріти: перевіряйте місця й час онлайн перед заходом.
• iOS/Android можуть очищати дані браузера при нестачі місця. Офлайн-кеш не є
  довічним сховищем.
• Офлайн-обкладинки необов'язкові і доступні лише після їхнього збереження.
• Встановлення через Telegram WebView може не показати кнопку PWA.
  Використайте Safari (iPhone) або Chrome (Android).

ПЕРЕВІРКИ
• Python: py_compile успішний; JavaScript: node --check успішний.
• Unit-тест логіки Service Worker (Node): офлайн HTML, ігри, очищені публічні
  події, заборона офлайн-записів — успішний.
• Повний браузерний тест у Chromium у цій сесії недоступний через локальні
  обмеження тестового середовища (ERR_BLOCKED_BY_ADMINISTRATOR).
• Реальний тест на Telegram, Safari/Chrome і після деплою ще потрібен.

Збережено чинну версію серверних маршрутів і платних подій v4.4.
Налаштування Supabase та еквайрингу monobank не змінювалися.
