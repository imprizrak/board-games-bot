Styloteka 5.3.48 — без BGG-автозаповнення

База: 5.3.47 (компактна прозора нижня панель із легким блюром).

Видалено:
- Автозаповнення з BoardGameGeek (для нових та існуючих ігор), екран попереднього перегляду BGG і залежність від BGG_API_TOKEN.
- POST /api/games/autofill, імпорт game_autofill.py та завантаження віддалених обкладинок через BGG.
- Приховані поля BGG-обкладинок та відповідні JS/CSS-функції.

Збережено:
- Ручне створення й редагування ігор, завантаження своїх обкладинок, описів, тегів та PDF правил.
- Можливість додати посилання на правила і YouTube-огляд вручну.
- Дві кнопки ручного пошуку (YouTube-огляд / Google-правила), які використовують назву гри та не потребують ключів.
- Події, квитанції, модерацію, інструменти, нижню навігацію та попередню логіку бота.

Встановлення:
1. Замініть у корені GitHub два файли: app.py та index.html із цього ZIP.
2. game_autofill.py із попереднього релізу можна видалити з репозиторію — новий код його не імпортує.
3. Ключ BGG_API_TOKEN у Render більше не використовується; можна прибрати його з Environment вручну.
4. Commit у GitHub запустить автодеплой Render, якщо він увімкнений.
5. Supabase змінювати не потрібно. Існуючі картки ігор лишаються в базі без змін.

Зверніть увагу: кнопки пошуку ведуть до результатів пошуку, але нічого не заповнюють автоматично.
Оновлення не опубліковано в GitHub або Render автоматично.
