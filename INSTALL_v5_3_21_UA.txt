STYLOTEKA v5.3.21 — НОВІ ІГРИ В ГІЛКУ «НАСТІЛКИ»

ЩО ЗМІНИЛОСЯ
- Коли адміністратор додає гру або схвалює заявку іншого учасника, бот надсилає анонс лише в прив'язану гілку «Настілки».
- Збережено обкладинку, опис і кнопку «🎲 Відкрити гру».
- Якщо фото недоступне, запасне текстове повідомлення надходить у ТУ САМУ гілку.
- Якщо ID гілки ще не налаштовано, груповий анонс не надсилається в загальну стрічку або в іншу гілку.
- Анонси подій /seteventtopic і їхні нагадування залишилися окремими.
- Особисті сповіщення підписникам про нові ігри залишилися без змін.

СТАН БАЗИ
- Стовпець public.telegram_groups.game_thread_id вже додано в робочий Supabase boardgames.
- game_thread_id зараз NULL: гілку потрібно ще прив'язати командою адміністратора.
- SQL-файл TELEGRAM_GAMES_TOPIC_SETUP_v5_3_21.sql у ZIP для перенесення в інший проєкт / відновлення (повторний запуск безпечний).

ВСТАНОВЛЕННЯ
1. Збережіть копію поточного app.py з GitHub.
2. Замініть ЛИШЕ app.py у GitHub на app.py із ZIP. Умови створення подій та форми Mini App не змінювалися.
3. Дочекайтеся успішного автоматичного деплою Render з оновленого коміту.
4. Перейдіть у Telegram до групи «Стильотека» → гілка «Настілки».
5. Надішліть у цій гілці команду /setgamestopic від імені адміністратора групи.
6. У цій же гілці надішліть /testgamestopic. Бот має надіслати тестове повідомлення в «Настілки».
7. Додайте одну нову тестову гру (або схваліть заявку) і перевірте групову публікацію.

КОМАНДИ
- /setgroup — якщо бот відповідає, що група не підключена; виконувати в групі як адміністратор.
- /setgamestopic — прив'язка поточної гілки для нових ігор (лише адміністраторам).
- /testgamestopic — тестовий допис у прив'язану гілку (лише адміністраторам).
- /unsetgamestopic — вимкнути групові анонси про нові ігри до повторного /setgamestopic.
- /seteventtopic — прив'язка окремої гілки для анонсів і нагадувань про події.
- /testgroup — перевірка гілки подій.

УВАГА
- Нова версія коду НЕ завантажена в GitHub/Render цим пакетом.
- До заміни app.py стара версія продовжує постити нові ігри в загальну стрічку.
- Не підставляйте випадковий номер гілки вручну: /setgamestopic прочитає правильний ID із Telegram.
