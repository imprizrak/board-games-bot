STYLOTEKA v5.3.43 — рівні неонові кільця для «Вибір гравця»

ЗМІНИ
- Кольорові маркери пальців — ідеальні кола однакового розміру з двома концентричними неоновими обводками.
- Кольори: рожевий, бірюзовий, фіолетовий, блакитний та інші контрастні відтінки.
- Маркери динамічно з’являються під реальними пальцями (не фіксована сітка з 6 кнопок).
- Маркери не створюються заново під час переміщення пальців — рух плавніший без блимання.
- Збережено випадкове визначення переможця, анімацію рулетки, звуки, скидання і повноекранний режим.
- На iPhone максимальна кількість одночасних дотиків обмежена системою пристрою.

ВСТАНОВЛЕННЯ
1. Якщо v5.3.42 вже встановлено, заміни тільки index.html в GitHub на файл з цього ZIP.
2. Якщо немає, онови одночасно app.py та index.html з цього ZIP, але зверни увагу, що база даних повинна бути оновлена відповідно до попередніх версій.
3. Дочекайся завершення автодеплою Render. Закрий та відкрий бота в Telegram.
4. Перевір «Інструменти» → «Вибір гравця» на iPhone/Android.

ВАЖЛИВО: архів не встановлюється на Render автоматично. Поведінка на реальному iPhone ще потребує перевірки після встановлення.
