Styloteka v4.9 — повна фотографія на картках подій

У GitHub замініть ТІЛЬКИ index.html. Не змінюйте app.py чи інші файли.

Виправлення: фото найближчої події на Головній, фото подій у вкладці «Події» і попередній перегляд під час створення події більше не обрізаються (object-fit: contain; природні пропорції; обмежена максимальна висота).

Усі інші функції v4.9 збережені без змін.

Старі файли браузера можуть кешуватися; після розгортання оновіть Mini App (закрити й відкрити).
