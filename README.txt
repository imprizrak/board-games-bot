Структура проєкту:

bot.py - Telegram бот, який відкриває кнопку з веб-застосунком
server.py - сервер, який показує сторінку бібліотеки ігор і зберігає дані
index.html - сама сторінка бібліотеки (візуальний інтерфейс)
static/covers - тут зберігаються завантажені обкладинки ігор
static/rules - тут зберігаються завантажені PDF з правилами
games.db - база даних (створюється автоматично при першому запуску)

Перед запуском:
1. У bot.py вставити токен від BotFather замість ВАШ_ТОКЕН_ВІД_BOTFATHER
2. У bot.py вставити адресу сайту замість ВАША-АДРЕСА.com (після розміщення в інтернеті)
3. Встановити бібліотеки: pip3 install -r requirements.txt
4. Запустити сервер: python3 server.py
5. Запустити бота (в іншому вікні термінала): python3 bot.py
