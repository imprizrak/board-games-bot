STYLOTEKA — SHOP v3.2
=====================

ОНОВЛЕННЯ ТІЛЬКИ ІНТЕРФЕЙСУ

1. У GitHub (imprizrak/board-games-bot, гілка main) замінити ТІЛЬКИ index.html.
2. app.py, requirements.txt та налаштування Render не змінювати.
3. Дочекатися успішного деплою Render.
4. Повністю закрити Mini App у Telegram та відкрити заново.

Версія включає попередні функції Shop v3.1 (пошук, бажане, сортування),
а також вікно деталей предмета, склад ігрових наборів, можливі нагороди
Mystery Box, ймовірності випадіння, ціль накопичення, прогрес колекції,
фільтр рідкості та підтвердження перед покупкою.

Усі покупки й подарунки продовжують використовувати наявні серверні API
Shop v3. НЕ змінюйте робочий app.py на старий варіант.

Примітка: ціль накопичення та список бажаного зберігаються лише локально
в Telegram Mini App на пристрої, не синхронізуються між пристроями.

Перевірено:
- JavaScript syntax (node --check)
- Працездатність фільтрів, пошуку, вікон і підтвердження в Chromium
- Ширина екрана 320, 375, 390, 768 px: без горизонтального скролу
- Попередні маршрути сервера залишено без змін.
