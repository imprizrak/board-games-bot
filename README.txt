STYLOTEKA v4.3 — події, рамки, Telegram deep links

Що оновити в GitHub:
  1. Замінити index.html.
  2. Замінити app.py.
  3. Дочекатися статусу Live в Render.

Виправлення:
  • Декоративні елементи рамок аватарок винесені за фото. Перевірено в Chromium на мобільному екрані.
  • Повні описи подій і нагадувань у Telegram-групі: бот більше не обрізає текст до 500/1024/4096 знаків.
    У Telegram є ліміт на одне повідомлення, тому довгі тексти надсилаються окремими частинами,
    кнопки запису — під останньою частиною. Якщо є обкладинка, вона надсилається окремо.
  • Знято ліміт трьох ігор від одного учасника в події. Щоб додавати ігри, все ще потрібно записатися
    на подію. Повторний вибір тієї самої гри одним користувачем не дублюється.
  • Кнопка «Відкрити подію в Styloteka» з групового поста відкриває Telegram Mini App через
    startapp=event_<ID>, а не звичайний браузерний сайт без Telegram initData.
  • Після натискання «Я йду» або «Стати в чергу» Telegram ID користувача синхронізується
    зі звичайним профілем Styloteka, не перезаписуючи XP, стілси чи придбані предмети.

Увага до налаштувань:
  • У @BotFather має бути налаштована Main Mini App для цього бота. Якщо замість Main Mini App
    використовується named/direct Mini App, у Render задайте TELEGRAM_APP_SHORT_NAME (short name).
  • За замовчуванням Telegram username бота: @Stylogames_bot (підтверджено попередніми логами Render).
    За потреби в Render можна задати TELEGRAM_BOT_USERNAME з фактичною назвою.
  • Старі кнопки у вже опублікованих постах залишаться старими: нові посилання будуть у нових постах.
  • Самі публікації в групі, як раніше, тільки про події та нагадування.

Рекомендований тест після деплою:
  1. З іншого Telegram акаунта натиснути «✅ Я йду» під НОВИМ груповим анонсом.
  2. Натиснути «📅 Відкрити подію в Styloteka» — повинна відкритися саме Telegram Mini App,
     користувач не має бути «гість», а подія повинна підсвітитися.
  3. Вибрати 4+ різні настолки й перевірити, що вони збереглися.
  4. Опублікувати тестову подію з описом понад 4500 знаків і фото, перевірити всі частини.

Локально перевірено Python compile, JavaScript parse, CSS parse, розбиття довгих постів
на Telegram-сумісні повідомлення та зовнішній вигляд рамок у Chromium.
Реальні Telegram callback-и і deploy на Render треба перевірити після встановлення.
