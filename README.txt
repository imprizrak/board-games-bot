STYLOTEKA v4.7 — ВИПРАВЛЕННЯ ОФЛАЙН-ЗАПУСКУ НА IPHONE

Замініть ТІЛЬКИ три файли в корені GitHub репозиторію:
- sw.js
- offline.js
- offline.html

Важливо: app.py, index.html, offline-tools.js, платежі monobank, профілі, групові пости НЕ міняти.
Цей патч вимагає, щоб усі інші файли релізу v4.6 вже були на сервері.

Після успішного деплою Render:
1. Увімкніть інтернет.
2. Відкрийте Safari, введіть адресу вручну:
   https://board-games-bot-hkfp.onrender.com/offline
   (не відкривайте через Telegram або браузер всередині месенджера).
3. Натисніть «⬇️ Підготувати офлайн-запуск» і дочекайтеся
   ЗЕЛЕНОГО напису «✅ Готово для офлайн».
4. Safari → Поділитися → «На початковий екран» → Додати.
5. ОБОВ’ЯЗКОВО відкрийте встановлену іконку, поки інтернет ще є,
   натисніть «Підготувати офлайн-запуск» і знову дочекайтеся зеленого статусу.
   На iOS браузер і домашній вебзастосунок можуть мати окремі сховища.
6. Закрийте застосунок, увімкніть авіарежим і повторно відкрийте
   саме цю іконку Styloteka на початковому екрані.

Якщо екран досі показує помилку Safari, перевірте, чи іконка веде
на /offline, а не на / або Telegram-бота. Видаліть старий ярлик та
додайте іконку заново з правильної адреси (не очищуйте кеш, поки
не збережете потрібні локальні результати лічильників).

Що змінено:
- Надійніша інсталяція service worker: лише ключові офлайн-файли
  є обов'язковими; проблеми іконок чи необов'язкової сторінки не блокують її.
- Кеш-first для /offline, /offline.js, /offline-tools.js та /offline.html.
- Головний маршрут / у відсутності мережі показує збережені інструменти,
  якщо Service Worker уже був успішно встановлений.
- Статус «Готово для офлайн» з перевіркою кешу, кнопка повторної підготовки.
- Особисті дані, RSVP, платіжні API й записи в магазин не кешуються
  і не симулюються офлайн.

Межі:
- Telegram не гарантує старту Mini App без інтернету.
- Автономний запуск зі значка працює лише після успішного онлайн-збереження
  в контексті встановленого вебзастосунку; iOS може обмежувати зберігання даних.
- Повний офлайн-запуск на iPhone ще потрібно перевірити на реальному телефоні.
