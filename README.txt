Styloteka — ігри, які пропонують учасники події

Склад архіву:
- app.py (API для записаних учасників подій)
- index.html (вікно вибору та спільний список ігор)

У Supabase вже створена таблиця public.event_game_picks. Окремий SQL запускати не потрібно.

Як оновити:
1. У GitHub-репозиторії board-games-bot замініть ОБИДВА файли app.py та index.html.
2. Зачекайте статусу Live у Render.
3. Відкрийте Styloteka у Telegram, перейдіть у Події.
4. Запишіться на майбутню подію, потім натисніть «Обрати ігри для заходу».
5. Знайдіть гру в бібліотеці, натисніть «Додати». Можна запропонувати до 3 різних ігор.
6. Інші учасники бачать пропозиції, можуть запропонувати ту саму гру. Власний вибір можна прибрати.

Оновлення НЕ надсилає повідомлень про ігри в Telegram-групу. Збережено правило «тільки події».
Адмінський список ігор з редактора події збережено окремо від пропозицій учасників.

Перевірки: Python AST/compile, JS node --check, HTML унікальність ID, браузерний сценарій додавання гри у Chromium на ширинах 320, 375, 768 px.
Не перевірено: реальний запис у Supabase через Telegram користувача після деплою; перевірити першим тестом у Mini App.
