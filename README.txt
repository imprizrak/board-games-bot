STYLOTEKA — у Telegram-групу автоматично публікуються тільки події

Замінити в GitHub ЛИШЕ app.py із цього архіву.
index.html НЕ замінювати. Магазин, бібліотека й останні зміни інтерфейсу збережуться.

Вимкнено:
- групові анонси досягнень, XP та нагород;
- групові анонси нових ігор.

Залишено:
- публікації нових подій і нагадування за день до них;
- XP, нагороди, досягнення всередині профілю, стілси, покупки;
- особисті сповіщення підписників та адміністративні команди груп.

Серверні маршрути й база даних не змінені.
Після коміту дочекайтеся статусу Live на Render.
