5.3.50 — видалення подій з квитанціями
Замініть app.py та index.html у GitHub, дочекайтеся деплою Render.
Прибрано перевірку на наявність квитанцій перед видаленням. Захист окремих банківських платежів Monobank залишено. Пов’язані записи видаляються відповідно до чинних обмежень Supabase; при конфлікті показується помилка. Файли квитанцій у Storage не видаляються цим оновленням. Повернення коштів не здійснюється. Живий Supabase/Telegram не перевірено.
